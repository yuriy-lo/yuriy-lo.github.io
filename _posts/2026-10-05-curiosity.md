Recently my coding agent did something unexpected. It discovered my custom tool (it could find its usage in terminal history or in one of my previous coding sessions), ran it with the `-h` parameter, chose the parameter it needed (one I had never heard of before), and used it to test the generated code. If it were a junior developer, I would call it curiosity and would be very happy to see it. But GitHub implemented "curiosity" with a few lines of markdown. It is a small, fun moment in daily work, but it raises a lot of questions. What is the difference between personality and an instruction written somewhere in the brain?
