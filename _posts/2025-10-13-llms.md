Craziest thing with LLMs is that we have to treat them as humans.

* Feeling stuck on where to begin with a new task? Brainstorm it with chat bot.
* Want to add AI agent to your data processing workflow? Sanitize everything that agent sends to your API endpoints, expect payload to be ```{"user": "1; DROP TABLE users; -- "}```
* Generated some code with help of AI agent? Run all static checks and tests for it. And don't delete generated automation scripts after use, highly likely next time agent will fail to reproduce.
* Want to keep your secrets? Avoid publicly available AI services and read license agreement twice.
* Got some information after chatting with LLM? Don't trust blindly, do fact checking, ask for sources of data especially when dealing with numbers.
